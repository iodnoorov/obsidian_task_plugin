# Folder Task Board

Плагин Obsidian: одна Markdown-заметка — одна задача.

## Установка

1. Выполните `npm install` и `npm run build` (Node.js 22 или новее).
2. Создайте в хранилище папку `.obsidian/plugins/folder-task-board/`.
3. Скопируйте туда `manifest.json`, `main.js` и `styles.css`.
4. Включите Folder Task Board в сторонних плагинах Obsidian.

## Настройка и работа

В настройках добавьте колонки: название, например «Проект», и путь к существующей папке, например `Работа/Проект/Задачи`. Путь указывается от корня хранилища без начального слеша. В колонку попадают только `.md`-файлы непосредственно из этой папки, без вложенных папок. Порядок колонок можно менять кнопками со стрелками вверх и вниз рядом с каждой колонкой в настройках. На странице «Задачи» карточки колонок выводятся в этом порядке: слева направо, затем следующий ряд. Порядок сохраняется после перезапуска.

Число колонок в ряду настраивается от 1 до 6. На экранах шириной до 600 px отображается одна колонка.

Откройте общий экран кнопкой с галочками на ленте или командой «Folder Task Board: Открыть задачи». Нажатие на название открывает заметку; Ctrl/Cmd + нажатие открывает новую вкладку.

Галочка переименовывает `Название.md` в `[D]Название.md`. Снятие галочки возвращает название. Выполненная задача остаётся в колонке с зачёркнутым названием. Переименование выполняется через FileManager Obsidian: обновление ссылок зависит от настройки Obsidian «Автоматически обновлять внутренние ссылки». При конфликте имён существующий файл не перезаписывается.

Команда «Создать задачу», кнопка «Новая задача» и кнопка «+» в колонке открывают окно с названием и выбором колонки. Создаётся пустая заметка, которая сразу открывается.

Команда «Создать задачу из выделения» подставляет выделенный текст в название. Исходный текст остаётся без изменений. Многострочное выделение перед созданием нужно сократить до одной строки. Недопустимые символы имени файла и префикс `[D]` в новой задаче отклоняются.

Плагин не создаёт папки автоматически. Если папку переименовали или удалили, исправьте путь в настройках колонки.

## Проверки

`npm test` — проверки имён, путей и префикса выполнения.

`npm run build` — строгая проверка TypeScript и сборка `main.js`.

Для ручной проверки в тестовом хранилище: добавьте колонку, создайте задачу, отметьте и снимите выполнение, попробуйте создать дубль, создайте задачу из выделения и проверьте перенос четвёртой колонки при ширине сетки 3.

## Списки по датам

Над доской есть выбор даты, кнопки предыдущего/следующего дня и «Сегодня». При создании задачи дата подставляется из доски; её можно изменить в окне создания.

Даты хранятся в свойствах заметки:

```yaml
---
task_date: '2026-11-16'
task_closed: '2026-11-18'
---
```

`task_date` — первый день показа. Незавершённая задача видна в этот день и во все последующие. При выполнении устанавливается `task_closed` — фактический сегодняшний день, независимо от выбранного дня доски. Выполненная задача видна до этой даты включительно. Снятие галочки удаляет `task_closed`. Галочка отображает текущее состояние задачи также при просмотре прошлых дней.

У старых заметок без `task_date` используется дата создания файла. Для старых выполненных заметок без `task_closed` используется дата изменения файла: точную дату закрытия при необходимости внесите вручную. При выполнении или повторном открытии задачи `task_date` записывается в свойства, если отсутствует. Свойства можно редактировать в Obsidian; доска обновляется автоматически.

В контекстном меню редактора при наличии выделения доступен пункт «Новая задача из выделения».

Колонки одного ряда растягиваются до высоты самой высокой колонки этого ряда.

## Перенос задач между колонками

На компьютере перетащите строку задачи в другую колонку. Целевая колонка подсвечивается. Сам файл заметки перемещается в папку этой колонки через FileManager Obsidian; название, содержимое, даты и префикс выполнения сохраняются. Обновление внутренних ссылок зависит от настройки Obsidian «Автоматически обновлять внутренние ссылки».

Перенос в ту же папку ничего не меняет. При совпадении имени перенос отклоняется без перезаписи. Порядок задач внутри колонки можно менять перетаскиванием. Перенос меняет колонку для всех дат просмотра: история принадлежности к проектам не сохраняется.

Используется стандартное перетаскивание HTML. Сенсорное перетаскивание на Android пока не проверено.


## Ручная сортировка

Перетаскивайте задачу выше или ниже другой задачи в той же колонке. Линия показывает место вставки. Можно также переносить задачу из другой колонки сразу на нужную позицию. Отпускание на свободном месте колонки помещает задачу в конец её группы.

Активные задачи всегда выше выполненных. При выполнении задача уходит в конец группы выполненных. В каждой группе доступна ручная сортировка. Порядок общий для всех дат, сохраняется в `data.json` плагина, сохраняется при переименовании заметок и не теряет скрытые фильтром даты задачи. Файлы при сортировке внутри колонки не перемещаются и не переименовываются.
